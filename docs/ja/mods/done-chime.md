# done-chime

[English](../../mods/done-chime.md) | 日本語

長いターンが終わったら、音とトーストで知らせます。Claude に作業を任せて別の画面に移っていても、終わったことに気づけます。Claude がツールを使う許可を待っているときは、別の音を鳴らします。

## 鳴る音は 2 種類

| 音 | いつ鳴るか |
| --- | --- |
| 上がる 2 音 | `minSeconds` 以上かかったターンが終わったとき。トーストに「完了しました（2分13秒）」とかかった時間を出す。エラーなどで返答を終えずに止まったときは「途中で止まりました」 |
| 同じ高さの 2 音 | Claude がツールを使う許可を待っているとき。ターンの長さに関係なく鳴る |

自分で中断したターンと、サブエージェントのターンでは知らせません。

音は Python で正弦波から合成したもので、`done-chime/sounds/` に入っています。

## 設定

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `minSeconds` | `60` | これより短いターンでは知らせない |
| `sound` | `true` | オフにすると、トーストだけで知らせる |

## 動作環境

音が鳴るのは macOS だけです。ほかの OS ではトーストだけで知らせます。拡張機能ではトーストが出ないので、音だけで知らせます。
