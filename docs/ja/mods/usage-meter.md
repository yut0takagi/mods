# usage-meter

[English](../../mods/usage-meter.md) | 日本語

直近のターンのトークン数をステータス行に出し、セッション中の推移をグラフにします。プロンプトキャッシュが効いているかや、会話が膨らんできたかを、作業しながら確かめられます。

## ステータス行の読み方

```text
入力 52.1k / 出力 1.3k · キャッシュ 94% · 計 1.25M
```

| 項目 | 意味 |
| --- | --- |
| 入力 | 直近のターンの入力トークン数。プロンプトキャッシュから読んだ分と書いた分を含む |
| 出力 | 直近のターンの出力トークン数 |
| キャッシュ | 入力のうち、プロンプトキャッシュから読んだ割合 |
| 計 | 覚えているターン（直近 200 ターンまで）の入力と出力の合計 |

キャッシュの割合が急に下がったら、キャッシュが使えなくなった合図です。しばらく間が空いてキャッシュが切れたときや、会話の前半が変わったとき（モデルを切り替えた、など）に起きます。

## コマンド

| コマンド | 動き |
| --- | --- |
| `/usage-meter` | セッション中の推移をペインに出す |

ターミナルでは、ターンごとに 1 本の棒を描きます。下の青がキャッシュから読んだ入力、上のオレンジがそれ以外の入力と出力です。ほかの画面では、棒の形の文字（▁▂▃▅▇）を 1 行に並べます。

## 数え方

- サブエージェントのターンは数えません
- 覚えておくのは直近 200 ターンです

## 拡張機能で使うとき

ステータス行もペインも出ないので、`/usage-meter` を打つと、直近のターンの数と、直近 40 ターンの推移（棒の形の文字）を返答に出します。
