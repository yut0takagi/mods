# session-diff

[English](../../mods/session-diff.md) | 日本語

このセッションが Edit や Write で書き換えたファイルを、増えた行数・減った行数とともに並べます。ファイルを選ぶと差分を出します。`git status` はリポジトリ全体の変更を出しますが、session-diff が出すのは「このセッションが触ったファイル」だけです。複数のセッションで同じリポジトリを触っているとき、どこまでがこのセッションの仕事かを見分けられます。

## 何と比べた差分か

差分は `HEAD` からの、まだ commit していない変更です。commit すれば、そのファイルの差分は消えます。

- git が追跡していないファイルは、すべて増えた行として出します
- まだコミットのないリポジトリでは、空の状態と比べます
- 行数はファイルを編集するたびに取り直します。開いている差分のファイルを編集したときは、差分も取り直します

## コマンド

| コマンド | 動き |
| --- | --- |
| `/session-diff` | ペインを開き、編集したファイルの一覧を出す。「更新」ボタンで全部の行数を取り直す |
| `/session-diff <パス>` | そのファイルの差分を直接開く |

パスは、一覧に出る相対パス、絶対パス、ファイル名だけのどれでも引けます。編集していないファイルのパスを渡したときは、そう答えて一覧を添えます。そのファイルの中身は読みません。

## 拡張機能で使うとき

ペインが出ないので、`/session-diff` は一覧を、`/session-diff <パス>` は差分を返答に出します。返答に出した差分は会話に残り、Claude の文脈を使います。大きな差分を何度も出すときは気をつけてください。

## 制限

- 並ぶのは Edit・Write・NotebookEdit で変えたファイルだけです。Bash（`sed` やスクリプト、`git checkout -- <ファイル>` など）で変えたファイルは並びません
- 拒否されたり失敗したりした編集は数えません
- 覚えておくのは直近 100 ファイルまでです
- 10,000 文字を超える差分は、先頭だけを出します
