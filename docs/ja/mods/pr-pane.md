# pr-pane

[English](../../mods/pr-pane.md) | 日本語

セッションのディレクトリにあるリポジトリについて、開いている PR と CI の結果をステータス行とペインに出します。Claude に PR を作らせたあと、CI が通ったかを見にブラウザへ移らずに済みます。

## ステータス行の読み方

```text
PR 3 ✗1 ○1 ✓1
```

開いている PR が 3 件で、CI が失敗したものが 1 件、実行中が 1 件、成功が 1 件という意味です。CI のない PR は内訳に数えません。

失敗（✗）に数えるのは、チェックの結論が `FAILURE`・`TIMED_OUT`・`CANCELLED`・`ACTION_REQUIRED`・`STARTUP_FAILURE`・`ERROR` のどれかのときです。1 つでも失敗があればその PR は ✗、失敗がなく実行中のものがあれば ○ になります。

## コマンド

| コマンド | 動き |
| --- | --- |
| `/prs` | ペインを開き、その場で取り直す |

ペインには、PR ごとに CI の結果、番号（PR へのリンク）、タイトル、ブランチ（`head → base`）、作成者、draft かどうか、レビューの状態を並べます。

## 設定

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| `base` | 空 | この宛先ブランチの PR だけを出す（例: `main`、`develop`）。空ならすべて |
| `intervalSeconds` | `120` | 取り直す間隔（秒）。30 秒より短くはならない |

## GitHub への問い合わせ

取得には `gh pr list --state open --limit 30` を使い、ログイン中の `gh` のアカウントで GitHub の API を呼びます。`intervalSeconds` ごとに 1 回呼ぶので、既定なら 1 時間に 30 回です。1 回の呼び出しは 20 秒で打ち切ります。取れるのは最大 30 件です。

取れなかったときの原因と対処は [困ったとき](../troubleshooting.md#pr-pane-にpr-を取れませんでしたと出る) にまとめています。

## 拡張機能で使うとき

画面がないあいだは、定期的な取り直しをしません。見えない表示のために API を呼ばないためです。`/prs` を打つとその場で 1 回取り、結果を返答に出します。
